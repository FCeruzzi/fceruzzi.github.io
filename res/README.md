# /res Directory

Questa cartella è destinata a contenere il CV/PDF con i dati personali.

## Come usare

1. Posiziona il tuo PDF (es. `cv.pdf`) in questa cartella
2. I dati verranno usati per popolare le sezioni del sito portfolio

## Struttura attesa del PDF

Il PDF dovrebbe contenere:
- Informazioni personali (nome, email, location)
- Esperienza lavorativa
- Progetti
- Competenze tecniche
- Formazione/Educazione
- Contatti e link social
